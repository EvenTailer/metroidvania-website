Кибер-Утка: Анатомия способностей и гейтинг

Каждая способность героя служит ключом к закрытым зонам карты (Классический Metroidvania Ability Gating).

👁 Нейро-глаз «Спектр»
Механика: Сканирование комнаты клавишей Q. Проявляет скрытые лазеры, невидимые платформы и трещины в стенах.
Гейт: Снимает синие барьеры корпоративных лабораторий.
🦾 Кибер-рука с электроприводом
Механика: Парирование пуль и ударов в тайминг 0.15с (как в Nine Sols). При контакте — Hitstop 0.08с и контрудар.
Гейт: Силовым ударом выбивает бронированные гермодвери.
👟 Реактивные кроссовки (Dash)
Механика: Мгновенный рывок вперед с фреймами неуязвимости (i-frames 0.2с).
Гейт: Пролет сквозь фиолетовые лазерные решетки и кислотные ямы.
🪝 Трос-гарпун (Grapple Hook)
Механика: Выстрел тросом из запястья в неоновые точки подвеса на потолке с раскачкой.
Гейт: Преодоление пропастей промышленных шахт.

Feature-Sliced Design (FSD) Спецификация для React

          

            Структура будущего React-приложения (Vite + TypeScript) с разделением ответственности по слоям:
          

        


        

          

            
app/ (Инициализация)

            
Провайдеры тем, глобальные стили, роутер, авторизация по 3 паролям, IndexedDB хранилище картинок.

          

          

            
pages/ (Страницы)

            
DashboardPage, CurriculumPage, KanbanPage, HeroDossierPage, AiChatPage, GalleryVaultPage.

          

          

            
widgets/ (Виджеты)

            
SprintFocusBar, KanbanBoardWithDragDrop, AiChatWidget, ImageGalleryGrid, TopBarWithAuthor.

          

          

            
features/ (Действия)

            
voice-recording, split-step-to-sprint, upload-image-attachment, export-agent-context, auth-by-password.

          

          

            
entities/ (Сущности)

            
task (модель задачи), roadmap-step (шаг обучения), duck-implant (способность), author (член команды).

          

          

            
shared/ (UI Kit & Utils)

            
Базовые кнопки, модалки, SpeechRecognition API обертка, DeepSeek/Groq API клиент.
