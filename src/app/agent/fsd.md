# Feature-Sliced Design

Код только в `src/`. Слои сверху вниз: `app` → `pages` → `widgets` → `features` → `entities` → `shared`.

Импорт только вниз. `shared` и `entities` не импортируют `features`, `widgets`, `pages`, `app`. `features` не импортируют `pages` и `widgets`.

- `app` — сборка: провайдеры, store, роутер, глобальные стили, эта папка `agent`.
- `pages` — экраны. Страница не хранит базу доски.
- `widgets` — крупные блоки экрана (Sidebar, Topbar).
- `features` — действие пользователя (форма, диктовка, отправка).
- `entities` — типы и логика сущностей (task, note, chat).
- `shared` — речь, HTTP-клиенты, кнопки без знания доски.

Декомпозиция: максимум 500 строк на компонент/файл. Большие экраны и фичи разбивать на компактные блоки и подкомпоненты.

Новый экран — страница и маршрут (`#/имя` или роутер), не ещё один флаг внутри `App.tsx`. Не растить `mockup.html`.
